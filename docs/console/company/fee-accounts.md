# Fee Accounts

บัญชีธนาคารจริงที่ Platform Fee ที่หักจาก Merchant wallet ไหลไปเข้าในที่สุด — ไม่ใช่แค่ตัวเลขในระบบ แต่มีบัญชีปลายทางจริงตั้งค่าไว้ตรงนี้

![Fee Accounts](../../assets/screen-short/company-fee-accounts-list.jpg "หน้า Fee Accounts — ตัวอย่างบัญชี GSB ชื่อ 'ธเนศ พันธ์ทอง'")

| ฟิลด์ | รายละเอียด |
|---|---|
| Account Name | ชื่อบัญชี + UUID |
| Bank Account | เลขบัญชี + ธนาคาร |
| Status | Active/Inactive |
| ปุ่ม Create Fee Account | เพิ่มบัญชีรับ fee ใหม่ — เลือก Bank Code, กรอกเลขบัญชี+ชื่อ |
