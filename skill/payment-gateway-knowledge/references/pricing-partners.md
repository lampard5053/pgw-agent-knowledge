# เงื่อนไขการขายและ Partner

หน้านี้สรุปแผนราคาและโปรแกรม Partner ที่ใช้ขายจริง — เนื้อหาต่างจากหน้าอื่นในคู่มือนี้ตรงที่เป็น**ข้อมูลเชิงพาณิชย์ (commercial/pricing)** ไม่ใช่เอกสารทางเทคนิค

!!! danger "'WayPay' อาจเป็นแบรนด์เดียวกับ 'PGWay'/'payways.io' ที่เจอในเอกสารเทคนิค — ยังไม่ยืนยัน"
    เอกสารราคานี้ใช้ชื่อแบรนด์ **"WayPay"** ส่วนเอกสารฝั่งเทคนิคที่เคยสำรวจไว้เจอชื่อ `controller.pgway.work` (Portainer สำหรับ deploy bot), `bank-adapter-api.payways.io` (webhook endpoint จริง), และ "PGWay" เคยถูกยกเป็นตัวอย่างชื่อ PGW Provider ในหน้า [PGW API → Roles & Hierarchy](api/roles.md) — ชื่อทั้งหมดคล้ายกันมาก (WayPay / PGWay / payways.io) **คาดว่า**น่าจะเป็นแบรนด์เดียวกันเขียนคนละแบบ แต่ยังไม่มีหลักฐานยืนยันตรงๆ ว่าใช่

## ภาพรวม — 2 โมเดลหลัก

| โมเดล | ต่างกันยังไง | เหมาะกับใคร |
|---|---|---|
| **WayPay Payment Adapter** | เชื่อมบัญชีธนาคารตรง ไม่มีระบบ wallet/credit ให้ — ลูกค้าจัดการเงินเข้าออกและเครดิตเอง | คนที่มีระบบหลังบ้าน (เช่น ระบบ credit/wallet ของตัวเอง) อยู่แล้ว ต้องการแค่ "ท่อ" เชื่อมธนาคาร |
| **WayPay Payment Gateway** | ระบบเต็มรูปแบบ มี wallet, QR/Plain Text deposit, Topup/Settlement ให้ | คนที่เช่าระบบหลังบ้านอยู่แล้ว อยากมีช่องทางฝาก-ถอนเพิ่ม |

!!! tip "ตรงกับสิ่งที่เคยเห็นในเอกสารเทคนิคพอดี"
    "Payment Adapter" สอดคล้องกับเลเยอร์ **Bank Adapter/OpsDash** ที่เคยสำรวจไว้ (เชื่อมบัญชีธนาคารตรง ไม่มี wallet) ส่วน "Payment Gateway" สอดคล้องกับ flow เต็มที่เคยเห็นใน [PGW API → Transaction Flows](api/transaction-flows.md) (Deposit/Withdraw/Topup/Settlement + QR/Plain Text ตรงกับ Deposit Mode ที่เคยเห็นใน [Console → Payment Channels](console/payment/channels.md))

## WayPay Payment Adapter

| หัวข้อ | รายละเอียด |
|---|---|
| ค่าธรรมเนียม | เข้าทั้งหมดคิด **1.0%** ต่ำสุดที่ **0.5%** (ขาเข้าทั้งหมด) |
| ใครดูแลบัญชี | **บัญชีลูกค้าเป็นคนดูแลเอง** |
| การจัดการเงินเข้าออก/เครดิต | ลูกค้าต้องจัดการเอง — ระบบไม่มี wallet/credit ให้ |
| เหมาะกับใคร | คนที่มีระบบหลังบ้านของตัวเองอยู่แล้ว |

**ธนาคารที่รองรับ:**

| ประเภทบัญชี | ธนาคาร |
|---|---|
| บัญชีบริษัท | KBiz, KTB Biz, SCB Biz |
| บัญชีบุคคล | GSB |

## WayPay Payment Gateway

| หัวข้อ | รายละเอียด |
|---|---|
| ค่าธรรมเนียม User | Deposit **1.2%** — Withdraw **0%** |
| ค่าธรรมเนียม Merchant | Topup **1.2%** — Settlement **0%** |
| ช่องทางฝากที่รองรับ | **QR** และ **Plain Text** (แสดงเลขบัญชีตรงๆ) |
| เหมาะกับใคร | คนที่เช่าระบบหลังบ้านอยู่แล้ว อยากมีช่องทางฝาก-ถอนเพิ่ม |

!!! question "Withdraw/Settlement 0% แปลว่ายังไงกันแน่"
    ตัวเลข 0% สำหรับ Withdraw (ฝั่ง User) และ Settlement (ฝั่ง Merchant) — **คาดว่า**หมายถึงไม่คิดค่าธรรมเนียมเพิ่มสำหรับสองรายการนี้ (ต้นทุนถูกครอบคลุมจากฝั่ง Deposit/Topup ที่คิด 1.2% ไปแล้ว) แต่ยังไม่ยืนยันว่าเป็นนโยบายถาวรหรือโปรโมชั่นชั่วคราว

## ระบบ Account Partner — พาร์ทเนอร์จัดหาบัญชี

พาร์ทเนอร์ที่หาบัญชีธนาคารมาป้อนให้ระบบใช้งาน (ไม่ใช่เจ้าของบัญชีเอง)

| หัวข้อ | รายละเอียด |
|---|---|
| ส่วนแบ่งรายได้ | **0.1% – 0.3%** ต่อบัญชีที่พาร์ทเนอร์จัดหาให้ |
| ใครเป็นคนเลือก/จัดสรรบัญชี | **ทางเรา**เป็นผู้จัดสรรและเลือกบัญชีเองหลังพาร์ทเนอร์นำมาให้ |
| รอบจ่ายรายได้ | คำนวณและจ่ายทุก **30 วัน** |
| หน้าที่ของพาร์ทเนอร์ | ต้องให้ความร่วมมือในการจัดการและดูแลบัญชี |

## ระบบ Merchant Partner

สำหรับคนที่มีบัญชีธนาคารของตัวเองอยู่แล้ว และอยากนำมาใช้ผ่านระบบ Payment Gateway โดยตรง

| หัวข้อ | รายละเอียด |
|---|---|
| ส่วนลด | สูงสุด **0.4%** — เหลือ **ฝาก 0.8% / ถอน 0.6%** |
| ใครถือบัญชี | **ลูกค้า (merchant) ถือบัญชีเอง** |
| ธนาคารที่รองรับ | KBiz, KTB Biz, SCB Biz, GSB |
| สิ่งที่ทางเราช่วย | ดูแลบัญชีลดความเสี่ยงถูกล็อคจากธนาคาร + ให้คำปรึกษาการใช้งานและการปลดล็อคจากธนาคาร |
| ความรับผิดชอบคดีความ | **หากโดนคดีความ ผู้ใช้ต้องจัดการเอง** — ไม่ใช่ความรับผิดชอบของทางเรา |

!!! danger "ข้อควรระวังทางกฎหมาย/ความเสี่ยง"
    เงื่อนไข "หากโดนจากคดีความทางผู้ใช้จะต้องเป็นคนจัดการเอง" หมายความว่าความเสี่ยงทางกฎหมายจากการใช้บัญชี (เช่น บัญชีถูกอายัดเพราะเกี่ยวข้องกับคดีของบุคคลอื่นที่เคยใช้เลขบัญชีเดียวกัน หรือปัญหาบัญชีม้า) **เป็นความรับผิดชอบของ merchant เจ้าของบัญชีเอง ไม่ใช่ของ WayPay** — merchant partner ควรเข้าใจความเสี่ยงนี้ตั้งแต่ก่อนสมัคร

## เปรียบเทียบรวดเดียว

| | Payment Adapter | Payment Gateway | Merchant Partner |
|---|---|---|---|
| ใครถือบัญชี | ลูกค้า | (ผ่านระบบ WayPay) | ลูกค้า (merchant) |
| ค่าธรรมเนียมฝาก | 1.0% (ต่ำสุด 0.5%) | 1.2% (User) / 1.2% (Merchant Topup) | 0.8% |
| ค่าธรรมเนียมถอน | — | 0% | 0.6% |
| มี wallet/credit ให้ไหม | ไม่มี | มี | มี (ผ่าน Merchant Partner) |
| เหมาะกับ | มีระบบหลังบ้านเอง | เช่าระบบหลังบ้าน อยากเพิ่มช่องทาง | มีบัญชีเอง อยากได้ราคาถูกลง |

## คำถามค้าง

!!! question "ค่าธรรมเนียมชุดนี้สัมพันธ์กับ Platform Fee/Seller Fee/Payment Fee ที่เคยยืนยันไว้ยังไง"
    เอกสารเดิม (ดู [PGW API → Roles & Hierarchy](api/roles.md) และตารางคำถามตอบแล้วใน [คำถามที่ยังไม่มีคำตอบ](open-questions.md)) เคยสรุปว่าระบบใช้ **Platform Fee / Seller Fee / Payment Fee** เท่านั้น (ไม่มี Partner Fee) — ตัวเลข % ในหน้านี้ (เช่น Deposit 1.0-1.2%) **คาดว่า**น่าจะเป็นตัวเลขระดับเดียวกับ "Payment Fee" ที่ลูกค้าเห็น แต่ยังไม่ยืนยันว่า mapping ตรงกันเป๊ะหรือมีชั้นราคาเพิ่มเติมจากที่นี่

!!! question "'WayPay' คือแบรนด์เดียวกับ 'PGWay'/'payways.io' ที่เจอในฝั่งเทคนิคจริงไหม"
    ดูรายละเอียดใน callout ด้านบนของหน้านี้ — ชื่อคล้ายกันมากแต่ยังไม่มีหลักฐานยืนยันตรงๆ
